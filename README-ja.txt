気分と欲求の記録 — 初回公開手順（Windows 11 / GitHub Pages）

【アプリの内容】
・朝・夕それぞれ、気分 -3〜+3、欲求 0〜3 を記録
・一日につき一言コメント（最大500文字）
・一週間の一覧と、朝・夕別の気分・欲求グラフ
・日付を選んで過去の記録を編集
・CSV書き出しと読み込み
・Service Workerによるオフラインキャッシュ
・記録はブラウザのIndexedDBに保存し、アプリから外部サーバーへ送信しません

【GitHub Pagesで公開する】
1. PCのブラウザで https://github.com/ を開き、アカウントを作成／ログインします。
2. 右上の「+」→「New repository」を選びます。
3. Repository nameに例として mood-tracker と入力します。
4. Publicを選び、Create repositoryを押します。
5. 作成したリポジトリで「Add file」→「Upload files」を選びます。
6. ZIPを解凍し、中にある index.html / style.css / app.js / manifest.json /
   service-worker.js / icon.svg をリポジトリの最上位にアップロードします。
   README-ja.txtは必要なら一緒にアップロードして構いません。
   「mood-tracker-pwa」フォルダそのものではなく、その中のファイルをアップロードしてください。
7. Commit changesを押します。
8. リポジトリの Settings → Pages を開きます。
9. Build and deploymentで「Deploy from a branch」を選び、
   Branchは「main」、フォルダは「/(root)」を選びSaveします。
10. 数分待ち、Settings → Pagesに表示される公開URLを開きます。
    URLは通常 https://ユーザー名.github.io/mood-tracker/ の形式です。

【iPhoneに追加する】
1. iPhoneのSafariで公開URLを開きます（初回はオンライン必須）。
2. ページを開いたまま少し待ち、オフライン機能の準備が始まったことを確認します。
3. Safariの共有ボタン →「ホーム画面に追加」→「追加」。
4. 一度アプリを開き、画面が完全に表示されるまで待ちます。
5. 機内モードにして、ホーム画面のアイコンから起動できるか試します。
   その後、テスト記録を作成し、再起動後も残るか確認してください。
6. テストが終わったらテスト記録を削除するには、その日付を開き、気分・欲求・コメントをすべて空にして保存します。

【データについて】
・記録データはGitHubに送信されません。アプリのHTML/CSS/JavaScriptなどのプログラムだけが公開されます。
・記録は、そのiPhone上のSafari／ホーム画面アプリのサイトデータ領域に保存されます。
・SafariのWebサイトデータ削除、端末故障、ブラウザのストレージ消去などで失われる可能性があります。
・「データの管理」→「CSVを書き出す」で定期的にバックアップしてください。
・CSV読み込みは同じ日付の記録を上書きします。読み込み前に現在のデータをCSVで保存してください。
・iPhoneのSafariでプライベートブラウズは使わないでください。
・ホーム画面追加後も、まずはオンラインで一度起動し、キャッシュが済んだことを確認してください。

【更新するとき】
1. GitHubリポジトリのファイルを更新してCommit changesします。
2. iPhoneをオンラインにし、公開アプリを開きます。
3. Service Worker更新が反映されない場合は、アプリを閉じて再度開くか、Safariでサイトを再読み込みします。
4. データベース構造を変更する更新を行う場合は、先にCSVバックアップを取ってください。

【重要】
このアプリは個人用の記録補助ツールであり、診断・治療の代わりではありません。
欲求が非常に強くなったときに備え、信頼できる人や支援先への連絡方法も別に確保しておくと安心です。
